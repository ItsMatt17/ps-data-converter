# Planetary Science Data Converter
---
This data converter was made for Rutgers Planetary Science Department to convert a numerous set of isotopic datasets from XML to JSON. 


## Installation
---

```bash
$ git clone https://github.com/ItsMatt17/ps-data-converter
```

```bash
$ cd ps-data-converter
```

If using pip
```bash
$ pip install -U -r requirements.txt
```

```bash
$ python3 main.py
```

## Usage 

Note: to use this script you must add the xml files to the xml directory. In the python script at the top of the file change the `FILENAME` variable to the name of your desired file.
